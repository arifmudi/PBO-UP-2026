# AI Usage

Saya memanfaatkan ChatGPT untuk membantu memahami materi polimorfisme, pewarisan, duck typing, pernyataan `match`, dan `singledispatch`. ChatGPT juga membantu memberikan arahan dalam penyusunan kelas `DaftarHarga`, penerjemah perintah konsol, serta pemformat nilai berdasarkan tipe data.

Saya menggunakan bantuan AI untuk meninjau kode, memahami pesan kesalahan, dan menyusun jawaban refleksi pada LKM. Seluruh kode kemudian saya jalankan dan periksa kembali menggunakan pytest, mypy, Ruff, serta pemeriksa PBO. Saya tetap mempelajari hasilnya agar memahami fungsi dan penerapan setiap bagian program.
