# Refleksi P01

## 1. Hal yang Dipelajari

Pada praktikum P01, saya mempelajari cara menyiapkan struktur repository dan lingkungan kerja untuk pemrograman berorientasi objek menggunakan Python. Saya juga belajar menggunakan virtual environment serta menjalankan pemeriksaan dengan PBO checker, MyPy, dan Pytest.

Saya memahami bahwa program yang awalnya dibuat secara prosedural dapat diubah menjadi program berorientasi objek dengan membuat sebuah class yang memiliki data dan method. Pada tugas ini, data mahasiswa seperti nama, NIM, dan desa ditempatkan dalam class `Mahasiswa`, sedangkan proses perkenalan dibuat sebagai method `perkenalan()`.

## 2. Penerapan pada Kasus Nyata

Konsep class dan object dapat diterapkan pada sistem informasi mahasiswa di lingkungan kampus. Setiap mahasiswa dapat direpresentasikan sebagai sebuah object yang memiliki data seperti nama, NIM, dan asal desa.

Dengan pendekatan tersebut, data mahasiswa menjadi lebih terstruktur dan program dapat dikembangkan dengan lebih mudah apabila nantinya ditambahkan informasi seperti program studi, alamat, nilai, atau data akademik lainnya.
