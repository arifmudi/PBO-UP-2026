\# Refleksi P09



Pada tugas P09 ini, saya mempelajari penggunaan kelas abstrak, Protocol, dan Enum dalam pemrograman berorientasi objek menggunakan Python.



Saya memahami bahwa kelas abstrak dapat digunakan sebagai dasar bagi kelas turunannya dengan mewajibkan implementasi method tertentu. Saya juga mempelajari Protocol sebagai cara untuk menentukan kontrak perilaku suatu objek tanpa harus menggunakan pewarisan secara langsung.



Selain itu, saya mempelajari Enum untuk mengelola status sewa agar perubahan status lebih terstruktur dan sesuai dengan aturan yang telah ditentukan.



Selama mengerjakan tugas ini, saya juga belajar memperbaiki kesalahan kode, menjalankan pengujian menggunakan pytest, serta memeriksa kualitas kode menggunakan mypy dan pemeriksaan PBO.



Tugas ini membantu saya memahami penerapan konsep pemrograman berorientasi objek secara lebih terstruktur dalam sebuah program.
